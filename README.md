# KAGEGAN MOBILE (Unity, Android)

3D-аниме файтинг для Android: три играбельных бойца, режим Boss Rush из трёх волн с тремя боссами,
полигон, сенсорное управление, три пресета графики. Всё работает офлайн.

> **Статус.** Код проекта полностью написан и проходит компиляцию C# против эталонных сборок Unity
> (проверено вне редактора). **APK в этой среде не собирался и на устройстве не запускался** —
> здесь нет Unity Editor, Android SDK и подключённого телефона. Инструкции по сборке — ниже.

## Быстрый старт

1. Установите **Unity 6 LTS (6000.0.x)** с модулем **Android Build Support** (OpenJDK + SDK/NDK).
   `ProjectVersion.txt` указывает 6000.0.47f1; любая 6000.0.x подойдёт — Hub предложит открыть в установленной версии.
2. Откройте папку репозитория в Unity Hub. При первом открытии автоматически запустится
   **Kagegan → Setup Project**: создаст сцену `Assets/Kagegan/Scenes/Main.unity`, URP-ассет и настройки Android.
   (Если Unity попросит перезапуск из-за Active Input Handling — согласитесь.)
3. Нажмите **Play** — игра запускается сама из кода (меню, бой, всё остальное).
4. APK: **Kagegan → Build Android APK** → `Builds/Android/Kagegan.apk`.
   С подключённым по USB телефоном: **Kagegan → Build && Run on connected device**.
   Из командной строки:
   `Unity -batchmode -projectPath . -buildTarget Android -executeMethod Kagegan.EditorTools.KageganBuild.BuildAndroidCI -logFile -`
5. Сборка в облаке: `.github/workflows/android-build.yml` (GameCI). Добавьте секреты `UNITY_LICENSE`,
   `UNITY_EMAIL`, `UNITY_PASSWORD` и запустите workflow вручную во вкладке Actions — APK появится в артефактах.

## Что в игре

### Режимы
- **Босс-раш** — 3 волны подряд: в каждой две группы врагов и босс.
  1. **Лес разрушений** → босс **Дзякура, Змеиный мудрец**
  2. **Разрушенный город** → босс **Райдэн, Мститель грома**
  3. **Лунный храм** → босс **Сэйгэцу, Владычица луны** → финальная сцена на рассвете → экран результатов
- **Повтор боссов** — любой встреченный босс отдельно, на любой открытой сложности.
- **Полигон** — тренировочный двор как в оригинале (пагода, тории, сосны, соломенные чучела):
  бесконечная чакра, без перезарядок, статистика «Удар / Серия / Урон/с», режим спарринга.

### Играбельные бойцы
| Боец | Архетип | Техники | Ульта / добивание |
|---|---|---|---|
| **Кайто** | быстрый, длинные комбо, воздушные серии | Спиральная сфера (рывок), **Теневые двойники** (настоящие ИИ-бойцы, наносят урон и отвлекают врагов), Вихревой сюрикен (раскрывается в сферу ветра), Режим чакры (скорость/урон/реген) | «Ураган теней»: 4 клона подбрасывают цель, Кайто добивает сферой сверху |
| **Гэнрю** | тяжёлые удары, отбрасывание, броня | Огненный шар, Огненная волна (веер + горящая земля), **Дух-страж** (−50% урона, супер-броня, удары гигантских рук духа по площади), Контрстойка (перехват + мгновенная контратака) | «Падение небес»: метеор, ломает всё окружение в радиусе |
| **Мугэн** | технический, поглощение | **Поглощение** (держать: правая ладонь поглощает техники, снаряды и лучи спереди и накапливает энергию), **Выброс** (левая ладонь — луч, урон и ширина растут с накопленным), Чакровые стержни (высасывают чакру цели и замедляют — боссы тратят чакру на техники), Телепортация за спину | «Небесный разлом»: дождь стержней + столб энергии |

### Боссы (у каждого 3 фазы со своим поведением)
- **Дзякура**: змеиный рой (самонаводящиеся змеи по земле), змеиные путы (дальний захват с подтягиванием), сальто-уклонения и рывки, призыв адептов, ядовитый туман (фаза 2), «Великий змей» — линия взрывов из-под земли, валит деревья (фаза 3).
- **Райдэн**: заряженный удар-молния (рывок), огненные шары, мгновенный шаг за спину, контрстойка, **воздушное комбо** (подброс → прыжок → серия → добивание), фаза 3 — грозовая броня, ливень молний, город вокруг рушится.
- **Сэйгэцу**: костяные копья, самонаводящиеся лунные сферы, телепортации по арене, «Небесные ладони» (многоударная серия), **смена измерения** (лава / лёд / пустота с перекраской мира), фаза 2 — внешнее кольцо храма обрушивается и арена сжимается, фаза 3 — в центре поднимаются платформы, небо краснеет, «Истина пустоты» — огромная атака по центру арены (убегать из круга или уклоняться в нужный момент).

Смена фазы: кинематографический рык, баннер «ФАЗА N», реплика, событие арены.

### Боевая система
Лёгкие цепочки (4–5 ударов) с буфером ввода · тяжёлый удар · удар с разбега · **подброс** (тяжёлый после 2+ лёгких) → **погоня в прыжке** (лёгкий удар сразу после подброса) → воздушная серия → удар-обрушение · блок · **парирование** (блок в момент удара: оглушает врага, отражает снаряды) · рывок/уклонение с неуязвимостью · **идеальное уклонение** (замедление + окно контратаки) · **контратака** · захват и бросок (пробивает блок) · **добивание** (кнопка «Мощный» превращается в «ДОБИТЬ») · выносливость (блок, рывки, тяжёлые удары; пробитие защиты) · чакра для техник · **ярость** для ульты · **подмена** (рывок под комбо за чакру — выход из серии) · реакции на попадание спереди/сзади · отлёт, падение, подъём с неуязвимостью · **столкновение ударов** (clash: более тяжёлый удар побеждает) и снарядов (сильнейший пробивает) · затухание урона в длинном комбо · хит-стоп, тряска камеры, вибрация.

Попадания считаются по реальным позициям костей (кулак/стопа/корпус) в момент активных кадров — удар засчитывается, только если конечность действительно достаёт до тела.

### Управление
- Джойстик слева (плавающий), справа кластер: **Атака, Мощный, Блок, Рывок, Прыжок, Захват**, две ячейки техник + **Смена** (переключает техники 1–2 / 3–4), **Ульта**, «Цель» (смена цели), пауза.
- **Настройка раскладки**: Настройки → «Расположение кнопок» (перетаскивание, сброс), размер и прозрачность кнопок.
- **Геймпад**: стик — движение, A — атака, X — мощный, Y — прыжок, B — рывок, LB — блок, RB — техника, Back — смена техник, Start — пауза. Клавиатура (редактор): WASD, J/K/L, Space, Shift, U, 1–4, R, Tab, T, Esc.
- **Вибрация** с амплитудой на Android 8+ (лёгкая / средняя / сильная), отключается в настройках.

### Прогресс (офлайн, PlayerPrefs JSON)
Сложности **Ученик → Воин → Легенда** (открываются прохождением), рекорды времени, ранг S/A/B/C,
макс. серия, открытые боссы для повтора, все настройки и раскладка кнопок.

## Графика и оптимизация (цель — POCO C61: Helio G36, PowerVR GE8320, 4 ГБ)
- Персонаж = **один SkinnedMeshRenderer** (21 кость, 1 кость на вершину) → 1 вызов отрисовки (+1 на контур).
- Мир собран в несколько вершинно-окрашенных мешей с **одним материалом**; ломаемые объекты — отдельно.
- Свой **toon-шейдер** (2 полосы освещения, rim, вспышка попадания, туман, до 4 точечных «динамических» источников от взрывов/огня) и контур inverted hull. Работает и в URP, и во встроенном конвейере.
- Пресеты: **Низкий** (render scale 0.62, без контуров и динамического света, 45% частиц, 3 активных врага), **Средний**, **Высокий**.
- **Динамическое разрешение**: при просадке ниже цели render scale снижается, при запасе — возвращается.
- **Пулы**: снаряды, лучи, опасные зоны, кольца, трещины, молнии; частицы — из нескольких общих систем через `Emit` (без объектов на эффект).
- Без теней в реальном времени — мягкие blob-тени; без HDR/MSAA/depth texture в URP.
- ИИ «думает» 4–8 раз в секунду, а не каждый кадр; невидимые персонажи анимируются реже; токены атаки ограничивают число одновременно нападающих.
- Звук и музыка **синтезируются** при запуске (нет аудиофайлов → маленький APK и меньше RAM).
- Android: IL2CPP, ARM64, **только OpenGL ES 3** (Vulkan на GE8320 нестабилен), Gamma, авто-пресет Low на слабых GPU.

## Важные замечания
- **Персонажи оригинальные.** Вместо Наруто, Мадары, Момошики, Орочимару, Саске и Кагуи сделаны
  собственные бойцы с теми же архетипами и механиками (клоны, огонь и дух-страж, поглощение/выброс,
  змеи, молния, лунная богиня со сменой измерений). Персонажи Naruto — чужая защищённая IP.
  Имена, цвета и реплики собраны в `Roster.cs` и китах — их легко поменять.
- **Исходного Godot-проекта в репозитории не было**, а из трёх видео два оказались записями
  ветки Reddit. Ориентиром служили третье видео и скриншот (полигон, раскладка кнопок, интерфейс).
  Модели, анимации и звуки поэтому созданы процедурно в коде, без импорта ассетов и без Blender.
- Анимации — процедурные (позы + смешивание + дыхание, моргание, движения глаз, варианты idle,
  бег, повороты, отдача, падение и подъём), а не скелетные клипы из Blender. Если появятся
  риггованные модели, их можно подключить вместо `HumanoidRig`, сохранив всю боевую логику.
