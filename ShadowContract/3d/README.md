# Shadow Contract 3D — «Колокольня Орлова»

Трёхмерная версия стелс-игры Shadow Contract: одна полноценная миссия (вертикальный срез)
в духе Hitman / Assassin's Creed. Работает в браузере на телефоне и ПК, одним файлом.

**Играть:** открыть `dist/index.html` (файл самодостаточный, 2.1 МБ: код, модели, анимации, текстуры внутри;
сервер не нужен — можно открыть прямо из загрузок на телефоне).

## Сборка

```
npm install
npm run assets   # скачать и подготовить ассеты (CC0) → assets/
npm run build    # собрать dist/index.html
node tests/play.cjs <папка>    # 24 интерактивных теста геймплея (Playwright)
node tests/mobile.cjs <папка>  # мобильные тесты (эмуляция Pixel 7, касания)
```

## Технические решения

| Решение | Почему |
|---|---|
| Three.js r170, WebGL 2 | На Android WebGPU пока доступен не везде; WebGL 2 — везде. Babylon.js тяжелее по размеру сборки. |
| Свои коллизии (AABB + пространственная сетка 4 м), без Rapier | Персонаж кинематический, мир статичный; WASM-физика добавила бы ~1.5 МБ без выигрыша. |
| Граф путевых точек + A*, без Recast | Планировка известна; авто-связывание узлов по прямой видимости с проверкой ширины прохода. |
| Один HTML-файл (esbuild + base64) | Открывается на телефоне без сервера, как и прежняя 2D-версия. |
| Анимации meshopt + прореживание каналов | Убраны масштаб, смещения костей кроме таза, пальцы; 30 mocap-клипов = 575 КБ. |
| Звук синтезируется Web Audio | 0 байт ассетов; позиционирование PannerNode (HRTF на ПК), реверберация в помещениях. |
| Фиксированный шаг симуляции 60 Гц | Физика и ИИ не зависят от FPS; рендер — с переменным шагом. |
| Адаптивное разрешение + пресеты | Авто: телефон «Среднее», ПК «Высокое»; при просадке снижается разрешение, затем отключаются тени. |

## Системы

- **Стелс:** подозрение по зрению (конус, дальность зависит от освещённости точки: луна с учётом тени зданий + фонари),
  прямая видимость лучом, слух (шаги, падения, камни, крики; стены глушат), социальный стелс: запретные зоны, крыши,
  подозрительные действия (лазание, спринт рядом, перенос тела, «гусиный шаг» в людном месте), маскировка, толпа.
- **ИИ охраны:** патруль/пост → любопытство → расследование (идёт к последней известной позиции) → обыск (зовёт соседей
  голосом, будит оглушённых) → подтверждение (1.25 с крика «Тревога!» — пока горит «!», его можно устранить) → тревога = провал.
  Проверка пропавшего напарника, открытой двери на посту. Восприятие 10 Гц, дальних — 4 Гц.
- **Устранения:** убийство/оглушение с любой стороны в любом состоянии, кроме тревоги; спереди — дольше и шумнее.
  Выравнивание позиций (motion warping с проверкой коллизий), синхронные анимации героя и жертвы, удар сверху с наведением,
  метательный нож (автонаведение, в т.ч. в верёвку колокола), камень-приманка, перенос и укрытие тел, переодевание.
- **Паркур:** перелезание низких препятствий (автоматически на бегу), лазание по фасадам и уступам, подтягивание,
  хват в прыжке, автопрыжок с края на спринте, перекат при приземлении, прыжок веры в сено, лестница внутри башни.
  Перила над обрывом — только осознанно (удерживая прыжок).
- **Камера:** обход препятствий лучами, плечевой сдвиг, контекстная дистанция, FOV-кик на спринте, ракурс устранения;
  «меньше движения» отключает кик и тряску.
- **Графика:** PBR-материалы (Poly Haven), ACES, IBL из процедурного окружения, тени луны (PCF/PCF Soft), фонари-источники
  из пула ближайших, световые конусы и лужи света, bloom и MSAA на «Высоком», плащ с вершинной анимацией, контактные тени.
- **Интерфейс:** загрузка, меню, брифинг с «возможностями», пауза, настройки (графика, чувствительность, инверсия,
  авто-камера, размер интерфейса, меньше движения, субтитры, маркер цели, отладка ИИ, громкость), поражение с советом,
  итоги с оценкой и испытаниями, автосохранение и «Продолжить миссию». Индикаторы подозрения — дуги у краёв экрана.
- **Отладка ИИ (F3 / настройки):** конусы зрения, маршруты, состояние и уровень подозрения, таймер до тревоги, круги шума, FPS/draw calls.

## Пути к цели (проверены автотестами)

1. Отпустить верёвку колокола во дворе, когда Орлов под ним — несчастный случай.
2. Перерезать верёвку ножом (со стены двора / с ящиков).
3. Удар сверху с крыши дома купца.
4. Подъём по фасаду башни → клинок.
5. Дверь башни (отвлечь стражника камнем) → лестница → люк → клинок.
6. Метательный нож.
7. Переодевание в звонаря → двор и башня без подозрений.
Отход: городские ворота или канализация.

- Текстуры: **Poly Haven**, лицензия **CC0** — cobblestone_floor_08, white_plaster_rough_02, castle_wall_slates,
  clay_roof_tiles_02, brown_planks_05 (уменьшены до 512 px).
